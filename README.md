# Аналитика психиатрической службы Иркутской области
Оценка динамика заболеваемости, состава пациентов и работы психиатрической службы Иркутской области

## Цель проекта:   
создание системы поддержки принятия обоснованных управленческих решений в повышении эффективности психиатрической помощи населению

## Целевая аудитория: 
Главный врач ОГБУЗ «Иркутский областной психоневрологический диспансер», заместители главного врача по лечебной и организационно-методической работе,  заведующий организационно-методическим отделом ОГБУЗ «Иркутский областной психоневрологический диспансер»

## Ожидаемый эффект от проекта:
Ускорение обработки статистических данных на 70,0%   
сокращение времени на анализ данных по заболеваемости населения психическими расстройствами и расстройствами поведения, по заболеваемости среди диспансерных и консультативных категорий пациентов, по  анализу работы психоневрологических медицинских организаций на 80,0%
